*Junior Embedded Engineer*

Onsite · Bengaluru · ECE / EEE / Instrumentation / related branches

City Greens is a fast-growing AgriTech startup building automation and AI-driven solutions for Controlled Environment Agriculture (CEA). Our platforms combine hardware, IoT, and AI to help modern farms, institutions, and agri-enterprises improve productivity, efficiency, and sustainability.

We design and build the electronics that run commercial farms — control panels, sensor networks, dosing and irrigation controllers, and the IoT devices that connect physical farm hardware to our software platform.

*Role overview*

We are looking for motivated embedded engineers to join our onsite hardware team. You will work on live, production-grade devices — writing firmware, integrating sensors and actuators, and building the controllers that growers and farm operators depend on every day. This is not a training internship. You will be contributing to real products from week one.

*What you will do*

Firmware development

Write and maintain firmware for microcontroller-based devices (ESP32, STM32, Arduino-class). Implement reliable control logic for sensors, pumps, valves, and dosing systems deployed in the field.

Sensor & hardware integration

Interface with analog and digital sensors (EC, pH, temperature, humidity, flow, level) and actuators. Handle communication protocols — I2C, SPI, UART, RS485/Modbus — and bring up new hardware from bare board to working device.

IoT & connectivity

Connect devices to our platform using MQTT and real-time data streams over WiFi/GSM. Build firmware that reports device state accurately and responds to remote commands reliably.

Testing, debugging & collaboration

Test and debug on real hardware using multimeters, oscilloscopes, and logic analyzers. Work within a structured team using GitHub for version control and code reviews. Write clean, maintainable code and share regular progress updates.
